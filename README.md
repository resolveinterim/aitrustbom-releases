# AI TrustBOM releases

This repository hosts the downloadable release builds of **AI TrustBOM**, a product of [Resolve Interim Ltd](https://resolveinterim.com). It contains release assets and this README only; it does not contain source code.

- Product site, pricing and documentation: <https://aitrustbom.com>
- Support: <support@aitrustbom.com>
- License: see [LICENSE.txt](LICENSE.txt). AI TrustBOM is proprietary software, not open source.

## Releases

Each release lists the self-contained `trustbom` binaries for Windows, Linux and macOS, and a `SHA256SUMS` file. Verify the checksum of a download before you run it.

No release has been published yet. Install instructions will be added here and on <https://aitrustbom.com/install/> when the first release is available.
